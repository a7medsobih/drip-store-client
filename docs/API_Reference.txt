# Global

## Base & Auth Header

| Item | Value |
|------|--------|
| API prefix | `/api/v1` (storefront), `/admin/v1` (catalog admin) |
| Auth | `Authorization: Bearer <accessToken>` |
| Content-Type | `application/json` (except product admin upload) |
| Cookies | **لا يوجد** — tokens في body فقط |
| CORS headers | `Content-Type`, `Authorization` |
| Access token TTL | 15m |
| Refresh token TTL | 7d (`type: "refresh"` في payload) |
| JWT payload | `{ sub, role, email }` |
| Roles | `user`, `admin` |

## Response Wrapper

**Success**
```json
{ "success": true, "message": "...", "data": {}, "errors": null }
```

**Error** (`error.middleware.js`)
```json
{ "success": false, "message": "...", "data": null, "errors": null }
```

## Static Files

| Path | Purpose |
|------|---------|
| `GET /uploads/products/{filename}` | صور المنتجات (المسار المحفوظ في DB: `/uploads/products/...`) |
| `GET /api/files/...` | static من `src/uploads` (قد لا يطابق مسار الرفع الفعلي) |
| `GET /` | `{ "message": "API is running" }` |

# Auth

## POST /api/v1/auth/register

### Description
تسجيل مستخدم + إرسال OTP للتحقق من الإيميل.

### Auth
Public

### Request (body)
| Field | Type | Required | Rules |
|-------|------|----------|-------|
| name | string | ✓ | model: 2–60 chars |
| email | string | ✓ | unique, lowercase |
| password | string | ✓ | يُhash |
| gender | string | ✓ | `male` \| `female` |
| mobile | string | | unique if sent |
| emailConsent | boolean | | default false |

**ملاحظة:** `auth.validation.js` فارغ — لا middleware validation.

### Response (201)
```json
{
  "success": true,
  "message": "User registered successfully",
  "data": {
    "user": {
      "id": "ObjectId",
      "name": "...",
      "email": "...",
      "mobile": null,
      "gender": "male|female",
      "role": "user",
      "emailConsent": false,
      "isActive": true,
      "isVerified": false,
      "createdAt": "...",
      "updatedAt": "..."
    },
    "otp": "123456"
  }
}
```
`otp` يظهر **فقط** لو `NODE_ENV !== "production"`.

### Notes
- 409: email/mobile مستخدم
- بعد التسجيل: `verify-otp` لتفعيل `isVerified`

# Suggested Backend Improvements

1. **Wishlist غير مُنفَّذ** — مطلوب module كامل أو إزالته من الـ design doc.
2. **`GET /api/v1/products/:id` مفقود** — الـ frontend مضطر يعتمد على list فقط.
3. **Prefix غير موحّد:** storefront `/api/v1` vs admin `/admin/v1` — يُفضَّل `/api/v1/admin/...`.
4. **User id inconsistent:** Auth → `id`، Profile → `_id`.
5. **Category field:** DB `title`، populate يرجّع `name` — توحيد في كل الـ responses.
6. **Auth بدون validation middleware** — أخطاء Mongoose بدل رسائل واضحة.
7. **`GET testimonials/public`** يرجع array مباشرة؛ باقي list endpoints تستخدم `{ items, pagination }`.
8. **Product admin response** بدون populate؛ public list مع populate — inconsistency.
9. **`/api/files` vs `/uploads`** مساران مختلفان لنفس الملفات.
10. **Subcategories route:** `GET /subcategories/:id/subcategories` — REST غير واضح؛ الأفضل `GET /categories/:id/subcategories`.
11. **لا rate limiting فعلي** — `rateLimiter.middleware` stub وغير مستخدم.
12. **لا logout / revoke refresh token.**
13. **Orders:** لا `GET /orders/:id` للتفاصيل.
14. **Refunds:** لا list للمستخدم — admin فقط.
15. **Testimonial refused typo في enum** — `refused` (ليس `rejected`) — توثيق للـ frontend.
16. **Register:** لا validation على password strength في الكود.
